# architecture/

Institutional architecture authority for IMIP.

## Contents

| Path | Responsibility |
|------|----------------|
| `GOVERNANCE.md` | Binding repository laws and ownership boundaries |
| `adr/` | Architectural Decision Records |
| `contracts/` | Interface and plugin contracts |
| `diagrams/` | Runtime, event, sequence, and data-flow diagrams |

## Rules

- Architecture documents define structure and constraints.
- Architecture documents do not authorize feature implementation by themselves.
- Only approved specifications under `specs/` may be implemented.
- Structural changes that rename or expand top-level architecture require architectural approval.
